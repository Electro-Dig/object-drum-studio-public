# 现场触发控制台指南

Client Show Console 是面向甲方现场人员的独立系统。技术人员先通过远程沟通完成设备、颜色和声音配置，甲方工作人员进入演出模式后只负责开始、暂停、复位和总音量。

## 第一次配置

1. 使用最新版 Chrome 或 Edge 打开网站，点击“连接 / 更换摄像头”，允许摄像头权限。
2. 固定摄像头和灰布，移走画面里的全部物件，然后点击“捕捉空场”。场景状态显示“Lab 已标定”即完成。
3. 点击“启用声音”。浏览器要求声音必须由一次人工点击开启，这是正常的安全限制。
4. 默认使用“10 色对应 10 音效”。如果所有物件颜色相同，改为“同色随机音效”。
5. 每个槽位都可以改名称、启用状态和音量。
6. 依次放入每种木片，点击对应槽位的“镜头取色”，再点击左侧画面里的目标物件。
7. 点击“上传音效”选择 WAV、MP3、M4A 或 OGG；未上传时会自动使用内置测试音色。
8. 点击“试听”检查每个槽位。调整“最小物件”可以过滤小块噪点或允许更小的物件。

## 两种映射方式

### 10 色对应 10 音效

每个颜色固定播放自己的声音。绿色物件始终播放绿色槽位的音效，适合需要明确声音组织的现场。

### 同色随机音效

系统只使用第一个启用槽位的颜色进行识别；每当该颜色的新物件进入画面，就从所有启用的声音槽位中随机选择一个声音。其他九个槽位仍然用于上传和管理声音，不再分别取色。

## 交给甲方运行

1. 点击“进入演出模式”。
2. 甲方点击“开始运行”。系统会自动检查摄像头和声音；缺少的设备会引导重新连接。
3. 新物件进入整个摄像头画面时播放一次。多个物件同时进入时，声音可以重叠。
4. 物件一直停留在画面内不会重复播放；离开后再次进入，可以再次触发。
5. “暂停运行”保留识别但关闭声音触发。
6. “复位”清空计数和触发记录。当前已经在画面中的物件不会因为复位而立即重播。
7. 技术人员需要修改颜色或音效时，点击“返回配置”。

## 跨电脑迁移

配置完成后点击“导出配置包”。文件包含颜色规则、槽位设置和已经上传的短音效。换电脑后打开网站并点击“导入配置包”，然后重新允许新电脑的摄像头和声音权限。

摄像头设备不会写入配置包，因为不同电脑的设备 ID 和浏览器权限并不通用。

空场背景也不会写入配置包。换电脑、移动摄像头、改变镜像、换布或明显改变灯光后，都要清空画面并重新点击“捕捉空场”。

## 现场排查

- 摄像头被拒绝：点击地址栏左侧的网站权限，重新允许摄像头，然后重连。
- 摄像头被占用：关闭会议软件、系统相机或其他使用摄像头的网页。
- 没有声音：点击“启用声音”，检查浏览器标签页、系统输出设备和总音量。
- 场景显示“需重新捕捉”：灯光、机位或背景变化过大，请清空画面后重新捕捉空场。
- 误识别太多：重新捕捉空场并逐色镜头取色、增加现场光照稳定性，或调高“最小物件”。
- 识别不到小物件：调低“最小物件”，并让目标颜色与背景形成更明显的差异。
- 没有捕捉空场时仍可运行，但此时状态会显示“HSV 兼容识别”，只建议临时排障使用。
- 临时断网：已经打开的页面会继续识别和播放；首次访问后，控制台外壳会缓存到本机以增强刷新恢复能力。
