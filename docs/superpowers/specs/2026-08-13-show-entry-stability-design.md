# 演奏模式放稳触发与手部误触防护设计

日期：2026-08-13  
适用分支：`feature/lab-recognition-v1`

## 目标

- 新物件进入演奏画面后，只有在位置、大小和颜色稳定一段时间后才触发声音。
- 放稳延迟可现场调整，范围 `0–800ms`、步进 `50ms`，默认 `100ms`。
- 同一轨迹首次稳定触发后固定本次声音身份；颜色短暂抖动不重播、不换声。
- 过滤明显属于手掌、手臂或放置动作的候选，不按肤色排除，因此不误伤红色、棕红色和橙色物件。
- 保留多物件同时进入、声音并发和“离场后再次进入可重新触发”的行为。

## 非目标

- 本轮不引入 MediaPipe、神经网络或远程推理服务。
- 不修改十色 Lab 原型、背景标定流程和音频引擎。
- 不承诺识别一只长时间完全静止、尺寸和形状又与木片相同的手部小区域；若现场仍出现该极端情况，再增加手部关键点遮罩。

## 根因

当前数据流为：

`Lab 前景检测 → PadTracker → TrackColorResolver → EntryGate → 音频触发`

`TrackColorResolver` 能抑制单帧跳色，但 `EntryGate` 只判断 track ID 是否首次出现。放置过程中，手与物件形成的短暂混合前景只要连续几帧被归到棕红、红或橙色，就可能直接成为一次 entry。当前检测还只有最小面积限制，没有最大尺寸、紧凑度、宽高比和运动稳定性门槛。

## 方案

### 1. 稳定进入门

将 `EntryGate` 扩展为带待确认状态的稳定进入门。每个新 track 保存：

- 首次与最近新鲜观测时间；
- 最近的质心、面积、边界和 `ruleId`；
- 当前稳定起点；
- 是否已经触发；
- 首次触发时冻结的声音身份。

只有同时满足以下条件才输出 entry：

1. 观测是检测器本帧的新鲜结果，而不是 tracker 在 TTL 内保留的旧副本；
2. `ruleId` 连续一致；
3. 质心移动、面积变化和边界变化均在容差内；
4. 候选符合小物件的尺寸与形状范围；
5. 稳定持续时间达到用户设置的放稳延迟。

任一稳定条件被破坏时，只重置该 track 的稳定计时，不影响其他物件。稳定后输出一次，并冻结本次 entry 的 `ruleId`、`instrument` 和 `label`。只要 track 仍在画面中，后续颜色抖动都不会产生第二次 entry；track 真正消失后状态才释放。

### 2. 手部候选过滤

过滤使用几何特征而不是肤色：

- 最大面积占画面比例；
- 最大边界宽度/高度占画面比例；
- 宽高比；
- 前景面积相对包围框面积的紧凑度。

明显过大、过长或过于松散的候选不能进入稳定计时。正常圆形或略不规则木片应保留。默认阈值在内部固定，避免增加过多现场控制项；阈值通过合成测试覆盖，后续只在真实视频证据表明需要时调整。

### 3. 放稳延迟控制

- 配置区和演奏控制区共享同一个“放稳延迟”设置。
- 使用滑杆，范围 `0–800ms`，步进 `50ms`，默认 `100ms`。
- 修改后立即生效并保存到当前 profile。
- `0ms` 仍要求至少有连续新鲜观测和几何合法，不退化为单帧肤色触发。

### 4. 模式与状态

- 配置模式继续显示实时识别结果，便于调整颜色和机位。
- 稳定进入门持续维护画面内 track 状态；在暂停或开始运行时，已经在画面中的物件不会突然补触发。
- 只有 `calibrated-lab / ok / live` 状态下，稳定进入门输出的 entry 才能播放声音。
- 背景标定失效、重拍空场或运行状态重置时，待确认状态一并清空。

## 数据与兼容性

- profile 的 `recognition` 新增 `settleDelayMs`，缺失时归一化为 `100`。
- 保持 schema v2，旧配置包和现有本地 profile 可自动补默认值，不需要清空音效或迁移存储 key。
- `EntryGate` 默认延迟仍为 `0ms`，以保持仓库其他调用者与旧测试的兼容；控制台显式传入 profile 值。

## 测试与验收

必须先添加失败测试，再实现：

1. 短暂出现的棕红色手部候选不足 100ms，不触发。
2. 小木片稳定达到 100ms 后只触发一次。
3. 位置移动、面积突变或颜色变化会重置计时。
4. tracker 保留的重复 `observedAt` 不得累计稳定时间。
5. 过大、过长或低紧凑度候选不触发。
6. 两个合格物件可以在同一帧分别触发。
7. 已触发物件后续跳色不重播；离场并过期后再次进入可以重播。
8. profile 正确保存、归一化并同步两个延迟控件。
9. 原十色 Lab/HSV、音频重叠和演奏标定门禁测试继续通过。
